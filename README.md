# 《禁忌實驗：古堡逃脫》

## 線上遊玩

**[直接開啟遊戲](https://ivanpeng7.github.io/midterm/game/index.html)**

用瀏覽器開啟上方連結，即可閱讀開場信並開始逃脫，不需要下載專案或啟動伺服器。線上版本會隨 GitHub `main` 分支的發布更新。

完整操作、檔案、三階段謎題與測試紀錄見 [GAME.md](GAME.md)。

## 下載後遊玩

1. [下載完整專案 ZIP](https://github.com/ivanpeng7/midterm/archive/refs/heads/main.zip)，並解壓縮。
2. 保持解壓縮後的 `game/` 與 `asset/` 資料夾位於同一層。
3. 用 Chrome 開啟 `game/index.html`，按「明白，開始逃脫！」開始遊玩。

## 聲音控制

按「明白，開始逃脫！」後播放書房背景音樂與壁爐聲；翻書、密碼、透鏡、星座、水晶及開門操作有對應音效。主畫面及調查視窗右上方的「聲音：開／關」可切換靜音。重新開始時停止聲音，下一局按開始後才播放；切到其他分頁暫停，返回只恢復背景聲。

音檔沿用 `asset/` 的原檔名與內容；較長的單次音效只播放開頭短段，避免操作時堆疊。音訊被瀏覽器阻擋或讀取失敗時，仍可正常解謎與通關。

## 本機開發與測試

已安裝 Node.js 時，可在專案根目錄執行：

```powershell
node game/serve.js
```

等終端機顯示「遊戲網址」後，將 `http://127.0.0.1:4173/game/index.html` 複製到同一台電腦的瀏覽器，並保持伺服器視窗開啟。

`127.0.0.1` 代表你自己的電腦。沒有先啟動伺服器時，會出現「拒絕連線」；一般遊玩請使用上方的「直接開啟遊戲」連結。

修改原始模組後，先以 `node game/build-browser.js` 更新直接開檔的版本，再執行 `node --test`；`node tests/browser-check.js` 同時驗證直接開檔與本機網址（需已有 Playwright 與瀏覽器）。

一款以古堡書房為舞台的 2D 解謎遊戲。玩家扮演受困的魔法師學徒，調查房間中的物品、尋找線索並破解機關，最後解除大門結界逃出書房。

## 怎麼開始

1. 下載或解壓縮整個專案，保持 `game/` 和 `asset/` 資料夾位於同一層。
2. 用 Chrome 開啟 `game/index.html`。
3. 閱讀開場信件後，按「明白，開始逃脫！」開始遊戲。

不需要安裝額外套件。若背景音樂或音效沒有播放，仍可正常遊玩。

## 怎麼玩

- 點擊書房中的物件進行調查；手機也可以使用場景下方的調查按鈕。
- 調查視窗可按關閉按鈕或 `Esc` 返回書房；可用 `Tab` 選取操作項目，再按 `Enter` 使用。
- 按照找到的線索依序解謎、取得道具並操作大門。想重新開始時，使用畫面上的重新開始按鈕。
- 遊戲進度不會跨頁面重新整理保存；重新整理會開始新的一局。

## 三階段解謎

1. **密碼箱與魔法透鏡：**閱讀魔法書，從封面找到密碼 `1976`，調查垃圾桶內的密碼箱並取得透鏡。
2. **油畫與星座：**在油畫使用透鏡觀察隱藏圖案，對照星座圖，選出獅子座 ♌、巨蟹座 ♋、天蠍座 ♏，打開油畫暗格並取得水晶。
3. **大門與日月機關：**把水晶放入大門中央插槽，依魔法書的提示將太陽朝上、月亮朝右，再確認方向即可解除結界。
